# Development notes

## Requirements

- [Bun](https://bun.sh) (CI uses `oven-sh/setup-bun@v2`)
- Node.js `^20.19.0 || >=22.12.0` (required by Vite 8 and Nitro)

## Environment variables

None. The app reads no `process.env` or `import.meta.env` values.

## Scripts

| Script | Command | Purpose |
| --- | --- | --- |
| `bun run dev` | `vite dev` | Dev server on port 5173 |
| `bun run build` | `vite build` | Production build (client, SSR, Nitro output in `.output/`) |
| `bun run build:dev` | `vite build --mode development` | Unminified build |
| `bun run preview` | `vite preview` | Serves the last build, default port 4173 |
| `bun run typecheck` | `tsc --noEmit` | Type check |
| `bun run test` | `vitest run` | Unit tests in `src/**/*.test.ts` |
| `bun run lint` | `eslint .` | ESLint with Prettier rules |
| `bun run format` | `prettier --write .` | Format the repository |

CI (`.github/workflows/ci.yml`) runs typecheck, lint, test and build on pushes to `main` and on pull requests. It does not deploy.

## Project structure

```text
src/
  components/   AppShell, Court, PlayerToken, ExplanationCard, RotationControls, Onboarding
  domain/       rotation.ts (rules), rotation.test.ts, formations.json, types.ts
  i18n/         de.json, en.json, init and language detection
  lib/          storage.ts, settings.tsx, error capture and error page
  routes/       __root.tsx, index.tsx (Learn), quiz.tsx
  router.tsx    Router and QueryClient setup
  server.ts     Server entry with error wrapper
  start.ts      TanStack Start setup (error and CSRF middleware)
  styles.css    Colour tokens, utilities
```

`src/routeTree.gen.ts` is generated by TanStack Router from `src/routes/`.

## Local storage

All keys are prefixed `vb.`.

| Key | Content |
| --- | --- |
| `vb.settings` | `{ reduceMotion, sound, libero }`. Defaults: `false`, `false`, `true`. |
| `vb.language` | `"de"` or `"en"`. Without it the browser language decides. |
| `vb.onboarded` | `"1"` once the intro dialog is finished or skipped. |
| `vb.results` | Last 500 quiz answers: `{ mode, correct, at, detail }`. |

Reset from the browser console:

```js
Object.keys(localStorage).filter((k) => k.startsWith("vb.")).forEach((k) => localStorage.removeItem(k));
```

## Deployment

The live app runs on Vercel, linked to the GitHub repository. Pushes to `main` build and deploy; there is no `vercel.json` and no environment variables.

Checklist after a deploy:

- Vercel Authentication (Deployment Protection) is off for the production domain, otherwise visitors get a Vercel login.
- `/` and `/quiz` load in a private window and the intro dialog shows on first visit.
- Headings use Big Shoulders Display (Google Fonts reachable).
- `public/robots.txt` matches the intent; it currently allows all crawlers.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| `bun add` fails with "blocked by minimum-release-age" | `bunfig.toml` skips package versions younger than 24 h. | Pick an older version, or wait. |
| `vite build` fails with `MISSING_EXPORT` from `@tanstack/router-core` | `@tanstack/react-start` and `@tanstack/react-router` are out of sync. | Pin `react-router` to the version `react-start` depends on. |
| Vercel build fails with `BLOCKED_PACKAGE` | Vercel blocks `@tanstack/react-start` versions with a known advisory. | Update to a patched release, then redeploy. |
| Port 5173 is in use | Another dev server is running. | `bun run dev --port 5174` |
| Headings render in a fallback font | Google Fonts request failed. | Allow `fonts.googleapis.com` and `fonts.gstatic.com`. |
| `src/routeTree.gen.ts` changes after starting the dev server | TanStack Router regenerates it. | Commit the regenerated file. |
